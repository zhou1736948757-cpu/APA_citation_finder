# APA_citation_finder — requirements

## Core (required)
```
requests>=2.31
python-docx>=1.1
python-Levenshtein>=0.25
```

## Optional (lazy-loaded; never required for core flow)
```
# Exa semantic discovery (search_exa.py)
exa-py>=1.0.6

# Google Scholar fallback (search_google_scholar.py) — fragile, CAPTCHA-prone
scholarly>=1.7

# PDF metadata extraction for local papers (search_local.py)
PyMuPDF>=1.24

```

## Install
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Notes
- LLM support scoring (score_support.py) and Gate 8B entailment review
  (audit_entailment.py) read `.env`:
  `USE_LLM_SUPPORT=true LLM_API_KEY=... LLM_API_ENDPOINT=... LLM_MODEL=...`
  Without them both fall back to deterministic heuristics — the pipeline
  still runs, with `scoring_method=heuristic` logged.
- Optional sources are OFF by default; core flow (OpenAlex + Semantic Scholar
  + Crossref) requires no API keys.
